# File Compressor

A simple desktop application for compressing files and folders using Electron and Node.js.

## Features

* Select a folder from your computer
* Compress files into an archive
* Shows compression progress
* Simple and user-friendly interface
* Built with Electron and Node.js

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Electron
* Archiver

## How to Run

1. Clone this repository.
2. Open the project folder in the terminal.
3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npm start
```

## Project Purpose

This project was developed as a desktop application project to practice Electron, Node.js, file handling, and process management.
