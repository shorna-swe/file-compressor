Await can only be used from inside an async function.

To make a function async you simply put async before its declaration.

For example:


function add(x,y){
    return x+y;
}


To make this function async you have to do:


async function add(x,y){
    return x+y;
}

In tools.js I have given two functions:

1)
createAndStartDownload

it takes a url and a folder directory path and downloads the file in there.


2)
createAndStartCompression

It takes a folder directory and compresses that folder to folder.zip in its
parent directory.


Both of these give an object. And you can use 
obj.finished() function to see whether the download/compression finished
and obj.getProgress() to get the download/compression progress.


To get directory path you can use an "Open Dialog" 
I have written a  sample usage code for you.


```
   let path = ""
   const dir = electron.dialog.showOpenDialogSync({
        properties:["openDirectory"]
    }); 
    
        // As soon as this line runs, a Open popup will appear, and
        // whatever you select, will be inside dir[0].
    if (dir)
       path  = dir[0];

```

You can use that path for the above two functions.
Like this:

const dl = download("www.google.com", path);

or,

const cm = compress(path);
